# 地理通用方法论

> [!abstract] 一句话
> 地理不是背答案，是**拆题**——**先判层，再归因，后取证**。
> 三个模型（结构 / 归因 / 比较）管**想清楚**，四个训练法（框架 / 因果链 / 图表 / 拆题）管**练出来**。

## 一、思维模型（3 个）

### 1. 三层结构模型：要素 → 过程 → 结果

任何一个地理问题，都可以拆成这三层：

| 层 | 回答的问题 | 例子 |
|---|---|---|
| **要素层** | 有什么？（"是什么"） | 气候、地形、水文、人口、交通、产业 |
| **过程层** | 怎么变的？（"怎么变化"） | 风化、搬运、沉积、热力环流、城市化 |
| **结果层** | 为什么长这样？（"为什么这样"） | 地貌、分布格局、优势 / 劣势 |

> [!tip] 核心公式
> **要素 → 过程 → 结果**。答案里缺任何一层，都会被判"要素堆砌"或"结论无据"。

### 2. 归因模型（自然-人文-区位）

> [!warning] 这里我改了原来的写法
> 原版叫「五因模型」，但清单里 **"自然因素" 和 "区位因素" 不是同一层的东西**（区位里本来就装着自然+人文+技术），并列容易乱。
> 改成**两层三类**，套用时不重不漏：

| 类 | 装什么 | 典型关键词 |
|---|---|---|
| **自然** | 气候（光/热/水/温差）、地形、水文、土壤、生物 | 光照、热量、降水、地势、水系 |
| **人文** | 人口、市场、交通、劳动力、政策、技术、资金、历史基础 | 市场广阔、交通便利、政策支持 |
| **区位** | = 自然 + 人文在**特定空间位置**上的组合结果 | "靠近××港""位于××沿海" |

> [!note] 为什么这样改
> 答题时先问"这题是**纯自然**题，还是要落到**某个位置的区位优势**"。
> 前者只用第一行，后者要"自然 + 人文 + 位置"三条都写，**位置本身就是一条得分点**。

**检验法**：写完原因后倒着念一遍——"因为 A，所以 B，所以 C"，链条断在哪一环，就补哪一类。

### 3. 三比较法（区域题必杀）

| 比较 | 比什么 | 用在哪 |
|---|---|---|
| **横向** | 不同地区之间 | "与××相比，本地××的优势/劣势" |
| **纵向** | 同一地区不同时期 | "近十年来变化""城镇化前后" |
| **结构** | 自然 vs 人文、优势 vs 劣势、内因 vs 外因 | 综合题最后一段拔高 |

> [!tip]
> **区域地理 = 比较学**。凡出现"分析××的优势条件"，答案骨架就是"比出来"的，不是"列出来"的。

## 二、学习法（4 个训练）

### 1. 框架笔记法（比背知识点强 100 倍）

先把骨架立起来，再往里填细节。示例（大气专题）：

```text
://大气
    /要素：受热过程、垂直分层、气压场、风
    /过程：削弱 → 地面增温 → 长波辐射 → 逆辐射 → 温差
    /结果：气候类型、天气现象、逆温、局地环流
    /影响：农业（熏烟/地膜）、城市（热岛）、灾害（霜冻/污染）
```

> [!tip] 落地方式
> 每学完一个专题，先只写 4 个 `/` 开头的行，**不许写细节**——写得出说明框架在脑子里，写不出说明还没学懂。

### 2. 因果链训练

一条链写到底，不许跳步：

```text
纬度高 → 太阳高度角低 → 太阳辐射弱 → 气温低 → 蒸发弱 → 水汽少 → 降水少
```

用[[大气专题-课时1-8合并#①|课时 1]]实测一下这条链好不好使：

```text
青藏高原空气稀薄 → 削弱作用弱 → 太阳辐射强 → 但大气吸收地面辐射少 → 保温作用弱 → 气温低
```

> [!note] 为什么这条链值得反复练
> 它同时解释了"太阳辐射最强的地方却最冷"这个反常识点。**能自洽解释反常识，才算真的掌握模型。**

### 3. 图表信息提取（图表占分近 60%）

四步读图，按顺序别乱：

1. **读坐标 / 方向 / 经纬度 / 比例尺** —— 先搞定"这图在说什么"
2. **读趋势** —— 上升、下降、波动
3. **读异常** —— 极值、拐点、与常识不符的点（**出题人最爱在这下手**）
4. **解释异常** —— 回到归因模型找因

### 4. 题目拆解法（所有题型通用）

拿到题先回答三个问题：

| 问自己 | 选项 |
|---|---|
| 属于哪一**层**？ | 要素 / 过程 / 结果 / 影响 / 对策 |
| 属于哪一**类因**？ | 自然 / 人文 / 区位 |
| 材料给了哪些**证据**？ | 图 / 表 / 趋势 / 文字 / 数据 |

## 三、做题法（选择题 / 大题）

### 1. 选择题：排除 → 常识 → 趋势

- **排除法**：违反地理常识的先删（纬度越高越冷、沿海更湿润、山地迎风坡降水多）
- **常识法**：用常识把"可能对但不符合材料"的选项筛掉
- **趋势法**：图表题的答案方向被**曲线趋势**锁定，别离开图空想

> [!warning] 高频陷阱（来自课时笔记的真实踩坑）
> - **方向反了**："吹东北风"是**风从东北来**，不是吹向东北 → 去向要差 180°
> - **层次混了**："热的地方气压低"只在**近地面**成立，**高空相反**
> - **绝对化了**："沙尘气溶胶只降温"→ 错，它是**降温 + 增温 + 凝结核**三条并存
> - **默认值错了**："城区一定比郊区热"→ 错，热岛强度**可以为负**（冷岛）

### 2. 大题：模板化表达

```text
① 描述现象   —— 只写材料给的事实，不加解释
② 解释原因   —— 套「自然 / 人文 / 区位」，每条都是"因 → 果"
③ 写影响/对策 —— 分有利 + 不利，或分工程 + 非工程
```

具体专题模板见：

- [[大气专题-课时1-8合并#⑧|课时 8]] —— 昼夜温差 / 降水差异 / 环流强弱三套模板
- [[大气专题-课时1-8合并#⑦|课时 7]] —— 降水差异的五角度拆解

## 四、踩坑清单

**思维层面**

- 别死背知识点 —— 地理是**逻辑学科**，背结论无法迁移
- 别分割自然与人文 —— 它们互相解释（城市热岛既是人文也是自然过程）
- 别只看结论 —— 判分看**因果链**完整性
- 别写空话 —— 必须落到「**要素 + 过程 + 结果**」才算答案

**操作层面**

- 别忽略图表 —— 图表是主要信息源
- 别只写一方向 —— 温差题只写"白天"必丢一半分
- 别把"描述"和"解释"混在一句里 —— 描述用材料语言，解释用地理术语
- 别漏"位置" —— 区位题里"靠近××"本身就是得分点，不是废话
- 别忘了分值提示点数 —— "6 分"通常意味着 3 个要点以上

## 五、自测

> [!question] 用模型自检
> 1. 随手挑一道做过的大题，把它拆成"哪一层 + 哪一类因 + 哪条证据"三栏，能不能填满？
> 2. 用因果链写出"城市规模扩大 → 夜晚近地面风增强"的完整链条（提示：[[大气专题-课时1-8合并#⑧|课时 8]] 模板 3）。
> 3. 找一个你认为"反常识"的地理现象，看归因模型能不能自洽解释。
