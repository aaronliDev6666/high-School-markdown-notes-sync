- 专题：单体的拆分（由聚合物推断单体）
  - 核心原理
    - 聚合物由单体通过**加聚反应**或**缩聚反应**形成
    - 单体拆分是聚合反应的逆过程
  - 一、加聚物的单体拆分
    - 加聚物特点：主链仅由碳原子构成，无杂原子（如 O、N）
    - 拆分方法：将主链每两个碳原子断键，恢复双键或三键
      - 例1：聚乙烯 $\ce{-[CH2-CH2]_{n}-}$ → 单体为 $\ce{CH2=CH2}$
      - 例2：聚氯乙烯 $\ce{-[CH2-CHCl]_{n}-}$ → 单体为 $\ce{CH2=CHCl}$
      - 例3：聚丙烯 $\ce{-[CH2-CH(CH3)]_{n}-}$ → 单体为 $\ce{CH2=CH-CH3}$
    - 共聚物的拆分：按不同链节分别处理
      - 例：丁苯橡胶 $\ce{-[CH2-CH=CH-CH2]-[CH2-CH(C6H5)]-}$ 
        → 单体1：$\ce{CH2=CH-CH=CH2}$（1,3-丁二烯）
        → 单体2：$\ce{CH2=CH-C6H5}$（苯乙烯）
    - 特殊结构：主链含双键的加聚物（如聚乙炔）
      - $\ce{-[CH=CH]_{n}-}$ → 单体为 $\ce{CH≡CH}$
    - 可视化：加聚物拆分流程图
      ```mermaid
      graph LR
      A[加聚物主链: -C-C-C-C-] --> B[每两个C断开]
      B --> C[恢复双键]
      C --> D[单体: C=C]
      style A fill:#e1f5fe
      style D fill:#c8e6c9
      ```
  - 二、缩聚物的单体拆分
    - 缩聚物特点：主链含杂原子（如酯键 $\ce{-COO-}$、酰胺键 $\ce{-CONH-}$、醚键 $\ce{-O-}$ 等）
    - 拆分方法：寻找断键位置，**加上水分子**（水解逆过程）
      - 1. 聚酯类
        - 通式：$\ce{-[O-R-O-CO-R'-CO]_{n}-}$ 或 $\ce{-[O-R-CO]_{n}-}$
        - 断键处：酯基 $\ce{-COO-}$ 处断开，加上 $\ce{H2O}$
          - $\ce{-COO- + H2O -> -COOH + HO-}$
        - 例：聚对苯二甲酸乙二醇酯（PET）
          - 聚合物：$\ce{-[O-CH2-CH2-O-CO-C6H4-CO]_{n}-}$
          - 加 $\ce{H2O}$ 后得：
            - 乙二醇 $\ce{HO-CH2-CH2-OH}$
            - 对苯二甲酸 $\ce{HOOC-C6H4-COOH}$
      - 2. 聚酰胺类
        - 通式：$\ce{-[NH-R-NH-CO-R'-CO]_{n}-}$ 或 $\ce{-[NH-R-CO]_{n}-}$
        - 断键处：酰胺键 $\ce{-CO-NH-}$ 处断开，加上 $\ce{H2O}$
          - $\ce{-CO-NH- + H2O -> -COOH + H2N-}$
        - 例：尼龙-66
          - 聚合物：$\ce{-[NH-(CH2)6-NH-CO-(CH2)4-CO]_{n}-}$
          - 加 $\ce{H2O}$ 后得：
            - 己二胺 $\ce{H2N-(CH2)6-NH2}$
            - 己二酸 $\ce{HOOC-(CH2)4-COOH}$
      - 3. 酚醛树脂（缩聚物特例）
        - 苯酚 + 甲醛 → 网状或线型聚合物
        - 单体拆分：在 $\ce{-CH2-}$ 桥键处断开，加 $\ce{H2O}$ 得苯酚和甲醛
    - 缩聚物单体拆分对比表
      | 聚合物类型 | 特征键 | 断键加水位置 | 单体类型 |
      |------------|--------|----------------|------------|
      | 聚酯 | $\ce{-COO-}$ | 酯基两边 | 二元醇 + 二元羧酸（或羟基酸） |
      | 聚酰胺 | $\ce{-CONH-}$ | 酰胺键 | 二元胺 + 二元羧酸（或氨基酸） |
      | 聚醚 | $\ce{-O-}$ | 醚键 | 二元醇（或环氧化物） |
      | 多糖（纤维素、淀粉） | $\ce{-O-}$（糖苷键） | 氧原子处 | 葡萄糖等单糖 |
  - 三、常见聚合物的单体快速判断口诀
    - 主链全碳—加聚物，两碳一断变双键
    - 主链有杂—缩聚物，酯键酰胺加水拆
    - 酚醛树脂看亚甲基，苯酚甲醛就出来
  - 四、典型例题（LaTeX 渲染结构式）
    - 已知聚合物结构：$\ce{-[NH-(CH2)5-CO]_{n}-}$，推断单体
      - 解法：主链含 $\ce{-CO-NH-}$，为聚酰胺（尼龙-6）
      - 加水断裂：$\ce{-CO-NH- + H2O -> -COOH + H2N-}$
      - 单体：$\ce{H2N-(CH2)5-COOH}$（6-氨基己酸）
    - 已知聚合物结构：$\ce{-[CH2-C(CH3)2]_{n}-}$，推断单体
      - 解法：主链全碳，每两个碳断键变双键
      - 单体：$\ce{CH2=C(CH3)2}$（异丁烯）
