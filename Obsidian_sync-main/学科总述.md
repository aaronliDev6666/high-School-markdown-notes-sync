# 地理通用方法论（Obsidian 版）

## 地理的底层思维模型（最核心）

### 1. 三层结构模型
- 要素层：气候、地形、水文、人口、交通、产业等“是什么”
- 过程层：风化、搬运、沉积、城市化、工业化等“怎么变化”
- 结果层：地貌、分布、格局、优势/劣势等“为什么这样”

![[通用表达式：要素 → 过程 → 结果]]

---

### 2. 五因模型（万能因果链）
- 自然因素：气候、地形、水文、土壤、生物  
- 区位因素：交通、市场、劳动力、政策、技术  
- 过程因素：季风、洋流、城市化、工业化  
- 人类活动：农业、工业、服务业、工程建设  
- 历史路径依赖：老工业基地、港口传统、文化积累

>**适用于所有原因题**

---

### 3. 三比较法（区域题必杀）
- 横向比较：不同地区之间  
- 纵向比较：同一地区不同时间  
- 结构比较：自然 vs 人文、优势 vs 劣势

> **区域地理＝比较学**

## 地理的学习方法论（泛用、可迁移）

### 1. 框架笔记法（比背知识点强 100 倍）
示例：

```
://气候
    /要素：气温、降水、季风、洋流
    /过程：热力环流、水循环
    /结果：气候类型、分布规律
    /影响：农业、城市、灾害
```

---

### 2. 因果链训练（纯文好像更会捏⪩. .⪨）
示例：

```
纬度高 → 太阳高度角低 → 气温低 → 蒸发弱 → 降水少
```

---

### 3. 图表信息提取（关键技能）
- 读图：方向、经纬度、比例尺、坐标  
- 读趋势：上升、下降、波动、极值  
- 读异常：与常识不符的点  
- 解释：回到<五因模型>

---

### 4. 题目拆解法（所有题型通用）
- 问题属于哪一层：要素 / 过程 / 结果 / 影响 / 对策  
- 问题属于哪一因：自然 / 人文 / 区位 / 过程 / 历史  
- 材料提供了哪些证据：图 / 表 / 趋势 / 文字

![[地理不是背答案，是拆题。]]

---

## 地理的做题方法论

### 1. 选择题：排除法＋常识法＋趋势法
- 排除法：不符合地理常识的先删  
- 常识法：纬度越高越冷、沿海湿润、山地降水多,etc 
- 趋势法：图表趋势决定答案方向

---

### 2. 大题：模板化表达（纯文赢麻了（ ˙³˙））

```
① 描述现象（材料给的）
② 解释原因（五因模型）
③ 写影响或对策（结构化）
```

---

## 地理注意事项（泛用、避免踩坑）

- 不要死背知识点：地理是**逻辑学科**
- 不要忽略图表：图表占 60%  
- 不要只看结论：要看**因果链**
- 不要分割自然与人文：它们互相解释  
- 不要写空话：**要素＋过程＋结果**才算答案
