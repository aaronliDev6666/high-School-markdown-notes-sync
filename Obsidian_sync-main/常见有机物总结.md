- 必修二有机化学
  - 烃类 (仅含C、H)
    - 烷烃 (C-C单键，链状，饱和)
      - 结构通式: **CₙH₂ₙ₊₂ (n≥1)**
      - 性质
        - 稳定，不与强酸强碱反应
        - 链状烷烃熔沸点随碳原子数增多而升高
      - 反应
        - 取代反应 (核心)
          - 与卤素单质在光照下反应
          - ![[例：CH₄ + Cl₂ → (光照) CH₃Cl + HCl]]
        - 氧化反应
          - 可燃性: 完全燃烧生成CO₂和H₂O
          - 不能使酸性KMnO₄褪色
    - 烯烃 (含碳碳双键，不饱和)
      - 结构通式: CₙH₂ₙ (n≥2, 单烯)
      - 性质
        - 因双键存在，化学性质活泼
        - 可使溴水褪色
      - 反应
        - 加成反应 (核心)
          - 与H₂、X₂、HX、H₂O等发生加成
          - ![[例： CH₂=CH₂ + Br₂ → CH₂Br-CH₂Br]]
        - 氧化反应
          - 可使酸性KMnO₄溶液褪色
          - 可燃性: 燃烧火焰明亮，伴有黑烟
        - 加聚反应
          - ![[例：nCH₂=CH₂ → (催化剂) -[CH₂-CH₂]ₙ-]]
    - 炔烃 (含碳碳三键，不饱和)
      - 结构通式: CₙH₂ₙ₋₂ (n≥2)
      - 性质
        - 与烯烃相似，因三键性质不饱和
      - 反应
        - 加成反应
          - 分步进行
          - 可与H₂、X₂等加成
          - 例: CH≡CH + 2Br₂ → CHBr₂-CHBr₂
        - 氧化反应
          - *可使酸性KMnO₄褪色*
          - 可燃性: 燃烧火焰明亮，**浓烈黑烟**
        - 加聚反应
          - 可发生加聚反应
    - 芳香烃 (以苯为代表)
      - 结构: 苯环，特殊稳定键
      - 性质
        - 难发生加成，易发生取代
        - 不能使酸性KMnO₄和溴水褪色
      - 反应
        - 取代反应 (主要)
          - 卤代反应: + Br₂ → (FeBr₃) 溴苯
          - 硝化反应: + HNO₃ → (浓硫酸，50-60°C) 硝基苯
        - 加成反应 (较难)
          - 与H₂加成: + 3H₂ → (Ni, 加热) 环己烷
        - 氧化反应
          - 可燃性: 燃烧火焰明亮，浓烟
  - 醇类 (**-OH** 直接连在烃基上)
    - 结构通式: R-OH
    - 代表物: 乙醇 (C₂H₅OH)
    - 物理性质
      - 有特殊气味，易挥发
      - 可与水以任意比例互溶
    - 反应
      - 与活泼金属反应
        - 与Na反应生成醇钠和H₂
        - ![[例： 2C₂H₅OH + 2Na → 2C₂H₅ONa + H₂↑]]
      - 氧化反应
        - 可燃性: 燃烧生成CO₂和H₂O
        - 催化氧化: 与O₂在Cu/Ag催化下生成醛或酮
        - 例: 2C₂H₅OH + O₂ → (Cu,△) 2CH₃CHO + 2H₂O
        - 能被强氧化剂直接氧化为酸
      - 酯化反应 (核心，与酸反应)
        - 酸脱羟基醇脱氢，生成酯和水
        - 可逆反应，浓硫酸催化加热
        - ![[例： C₂H₅OH + CH₃COOH ⇌ (浓硫酸,△) CH₃COOC₂H₅ + H₂O]]
      - 消去反应（分子内脱水生成烯烃）
        - 例: C₂H₅OH → (浓硫酸,170℃) CH₂=CH₂↑ + H₂O
      - 取代反应（分子间脱水生成醚）
        - ![[例：2C₂H₅OH → (浓硫酸,140℃) C₂H₅OC₂H₅ + H₂O]]
  - 酸类 (羧酸，含 **-COOH**) 
    - 结构通式: R-COOH
    - 代表物: 乙酸 (**CH₃COOH**)
    - 物理性质
      - 强烈刺激性气味，冰醋酸低温结冰
      - 易溶于水和有机溶剂
    - 反应
      - 酸的通性
        - 弱酸性，但酸性强于H₂CO₃
        - 使紫色石蕊变红
        - 与活泼金属反应生成H₂
        - 与碱反应生成盐和水
        - 与碳酸盐反应放出CO₂![[例： 2CH₃COOH + Na₂CO₃ → 2CH₃COONa + CO₂↑ + H₂O]]
      - 酯化反应 (核心，与醇反应)
        - 酸脱羟基醇脱氢，生成酯和水
        - 可逆反应，需浓硫酸催化加热
        - ![[例：CH₃COOH + C₂H₅OH ⇌ (浓硫酸,△) CH₃COOC₂H₅ + H₂O]]
  - 酯类 (含酯基 -COO-)
    - 结构通式: R-COO-R'
    - 代表物: 乙酸乙酯 (CH₃COOC₂H₅)
    - 物理性质
      - 密度小于水，难溶于水，易溶于有机溶剂
      - 具有芳香气味
    - 反应
      - 水解反应 (核心，酯化反应的逆反应)
        - 酸性水解: 可逆，生成酸和醇
          -![[例： CH₃COOC₂H₅ + H₂O ⇌ (H⁺,△) CH₃COOH + C₂H₅OH]]
        - 碱性水解: 不可逆，生成醇和羧酸盐
          - 也叫皂化反应 (制肥皂)
          - ![[例：CH₃COOC₂H₅ + NaOH → (△) CH₃COONa + C₂H₅OH]]
      - 氧化反应
        - 可燃性: 燃烧生成CO₂和H₂O
