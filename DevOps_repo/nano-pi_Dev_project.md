# 项目简介：Nano Pi M1 512MB RAM & FriendlyWrt 信息看板 & 无线控制面板设计

## 1. 项目概述
一块运行 FriendlyWrt 的nano pi m1 512mb ram，仅连接网线、电源，使用 32GB microSD 卡作为系统存储。目标是打造一个全屏信息显示与控制面板，实时展示系统状态、天气信息，并提供无线网络管理功能（客户端 / 热点模式切换）。适合直接接入显示器。

---

## 2. 硬件与环境
- **主控板**：nano pi m1, 512mb ram, 志强H3
- **外设**：网口、电源适配器、32 GB microSD 卡，HDMI接口，gpio，debug uart，3.5mm输出口
- **显示**：3.5英寸 480×320 LCD
- **状态**：裸板运行，无外壳

---

## 3. 操作系统
- **系统**：FriendlyWrt（基于 OpenWrt，保持最新稳定版）
- **核心要求**：启动后自动加载下文要求的控制面板界面

---

## 4. 功能模块划分

### 4.1 无线网络管理（WiFi 控制）
- **双模式开关**
  - **客户端模式**：连接到已有的 WiFi 网络，显示获取的**公网IP地址**
  - **热点模式 (AP)**：自身发射 WiFi 信号，供其他设备连接，显示本机 IP 和已连接设备列表
- **状态显示**：当前模式、SSID、IP 地址、信号强度、已连接客户端数量
- **切换交互**：提供一键切换按钮，切换时自动保存配置

### 4.2 天气页面
- **实时天气**：温度（摄氏度）、天气图标、体感温度湿度、风向、紫外线指数、日出日落时间
- **预报信息**：
  - 未来 3 小时预报（逐小时）
  - 未来 3 天预报（每日概要）
- 页面排版设计为卡片式布局，重点突出当前温度与天气图标

### 4.3 息屏显示页（待机屏保 / 常亮信息）
当无操作一段时间后自动切换至此页面，或作为默认启动画面。
- **实时数字时钟**（大字体，精确到秒）
- **系统信息**：
  - 设备 IP 地址（eth0 / wlan0）
  - CPU 占用率
  - 内核版本
- 可补充的轻量信息：内存占用、运行时长、存储剩余空间（可选）
- **呈现风格**：暗色背景，极简排版，适合长时间显示，低视觉干扰

---

## 5. UI 设计 & 排版建议

### 5.1 页面结构
- **主屏幕**：顶部为 WiFi 控制卡片，中部为天气卡片，底部为简洁系统状态条
- **息屏页**：全屏居中，上方大数字时钟，下方两行系统信息，隐去所有交互元素，触摸或移动鼠标返回主界面
- 所有页面采用响应式网格，适配 16:9 屏幕

### 5.2 签名与版权
- 在页脚或息屏页角落放置签名：`<aaronli.dev>`
- 设计为小字，不干扰主要信息，位置固定于屏幕右下角或底部中央

### 5.3 字体方案（自定义英文字体）
为了美观和可定制性，采用纯英文字体。推荐方案：
- **方法一（推荐）**：首次前端通过 Web Font 加载，使用 Google Fonts 中的字体，保存到本地便于后续使用 指定使用Google Fonts的Urbanist字体
- **方法二**：将字体文件（.ttf/.woff2）存于本地 `/www/fonts/` 目录，通过 CSS `@font-face` 引入，保证离线可用，我会提供字体文件
- 整体界面为纯英文（如 "Feels like 22°C", connected to Ethernet等）

---

## 6. 技术实现建议（供 Agent 开发参考）

- **后端**：在 FriendlyWrt 上运行轻量 Web 服务器（如 uhttpd + Lua/PHP，或 Python Flask），通过调用系统命令和 `/proc` 文件系统获取 CPU、内核版本、IP 等信息；WiFi 切换通过修改 `/etc/config/wireless` 并重启网络实现
- **前端**：单页 HTML/CSS/JS，全屏无边框，定时轮询后端 API 获取实时数据；使用 `visibilitychange` 或定时器实现息屏切换逻辑
- **天气数据**：前端直接请求免费天气 API，如果没有免费的实在不行接入deepseek最便宜的api问所有的天气信息，不需要保护密钥这就是我一个人用的本子
- **自动启动**：系统启动后自动打开全屏浏览器指向本地页面，或使用 framebuffer 直接显示（如搭配轻量图像库）

## 7. 补充说明

- 系统时间通过 NTP 自动同步，确保时钟准确
